# ServerRack

**Fabric • Minecraft 1.21.1 • Java 21**

Съёмочный мод для роликов: живая серверная комната — мультиблок-стойки с дымом,
офисные ПК-сетапы с аварийной видеостеной и режиссёрский детонатор с
десятью видами взрывов, бэкапом сцены на диск и послойным восстановлением.

Made by Denchy / ehalo.

## Модуль 1: Серверные стойки

Три мультиблок-стойки, ставятся одним блоком и растут вверх:

| Блок | id | Высота | Свет (актив/неактив) |
|---|---|---|---|
| Серверная стойка — маленькая | `server_rack_basic` | 2 | 10 / 4 |
| Серверная стойка — большая | `server_rack_advanced` | 3 | 12 / 5 |
| Серверная стойка — мейнфрейм | `server_rack_mainframe` | 4 | 13 / 5 |

- **Клавиша J** — вкл/выкл **все стойки** в радиусе 32 блоков разом.
  Логика: если хоть одна выключена — включаются все; иначе гаснут все.
  В actionbar пишется, сколько стоек найдено (или «не найдено»).
- Активные стойки светятся, из-под потолка над ними собирается **дым**.
- **Дым** (клиентский менеджер): частицы ползут по потолку от точки генерации.
- **Меню дыма — клавиша U**: частота эмиссии, частиц за раз, радиус по потолку,
  максимальная высота подъёма, плотность. Настройки синхронизируются
  по сети (C2S/S2C payload-ы), общие для сервера.
- **Гул кулеров**: ближайшая активная стойка в радиусе 20 блоков тихо визжит
  вентиляторами (клиентский локальный звук, на сцене его не слышно — только
  у камеры; луп ≈2,3 сек, голос один на стойку).

## Модуль 2: ПК-сетап и видеостена

Один предмет `pc_wall` разворачивает структуру **3×3**:

- нижний ряд — три сегмента стола (лево/центр/право),
- верхние два ряда — **6 мониторов 16:9** (3 колонки × 2 ряда).

Ломается целиком, детирование структур — по origin (desk_center).

- **Клавиша Z** — режим «**СЕРВЕРАМ ПИЗДА**»: все ПК-сетапы в радиусе 32
  переключаются в alert. Звук подтверждения один — из центра, без хора.
- Экраны режутся из общих текстур (alert 96×36; анимированная «матрица»
  96×864 = 9 кадров 96×96, frametime 2), UV с компенсацией на рамки.
- **Органика**: у каждого монитора свой мелкий сдвиг по высоте (−0.4..+0.35)
  и глубине (−0.03..+0.08), зональные оттенки матрицы (янтарь/голубой/тускло),
  верхне-правый монитор шумит, нижне-правый фликерит.
- Alert светит ярко (luminance 14), в обычном состоянии — 9.

## Модуль 3: Режиссёрский детонатор

Предмет `detonator` (макс. стак 1). Полностью независим от стоек и ПК —
работает с любым миром/постройкой.

### Жесты

| Жест | Действие |
|---|---|
| **ЛКМ по блоку** | Точка 1 (блок защищён — не ломается) |
| **ПКМ по блоку** | Точка 2 → мгновенный контур + **авто-бэкап на диск** |
| **ПКМ в воздух** | Меню детонации |
| **Shift + ПКМ в воздух** | Снять выделение |
| **Клавиша P** | БАБАХ сразу, без меню |

### Виды взрывов (10)

Шоквейв, Фитиль (змейка), Панкейк (этажи вниз), Шрапнель (хаотично всё),
Двухфазный (сперва пожар — потом детонация), **Расплавление ядра**
(искры → грибовидный взрыв), Залп (зенитки по секциям), Имплозия
(всё втягивает к центру), Срез (плоскость из края в край), Артобстрел
(снаряды сверху по столбам).

### Темп и слоумо

В меню: ×1 / ×0.5 / ×0.25. При темпе <1 сервер реально замедляется
через `TickManager` (20·speed TPS) — Replay Mod записывает это как
тяжёлую киношную сцену. Как только все работы кончились — TPS сам
возвращается к 20.

### Бэкап и восстановление

- Авто-бэкап пишется в `<мир>/serverrack_backups/<uuid игрока>_<измерение>.nbt`
  асинхронно (без лаг-спайка большого региона).
- Сохраняются: все блоки (палитра + id), block entities (сундуки и т.п.),
  закреплённые сущности — item-фреймы, стойки, картины. **Мобы и игроки
  в бэкап не попадают.**
- Бэкап лежит на диске и **переживает перезаход** — можно снимать серией.
- «Восстановить сцену» — послойная сборка снизу вверх (~2 слоя/тик),
  мерцание END_ROD по новому этажу; сущности возвращаются в конце.
- «Бэкап заново» — переснимает выделение в файл (на новый дубль).

### Разрушение — реализм без бардака

- Лута **нет**, дублей **несколько** — как на съёмочной площадке.
- Инвентари уничтожаемых контейнеров чистятся до нуля.
- ~10% шанс зацепить блок **сразу за границей** выделения — грязный
  живой край, как у настоящего взрыва.
- Падающие блоки летят с импульсами от эпицентра (или к центру — в Имплозии).
- Частицы: обломки блоков, огонь, дым, искры, вспышка, грибовое облако при
  мелтдауне; звуки взрывов и гуда огня с позиционированием по сцене.
- **Бумажки**: 2.5% шанса на уничтоженный блок — офисный мусор.
  6 видов с весами: помятая/согнутая/обгоревшая страница (частые),
  чертёж (средний), стикер и рваный чек принтера (редкие).

## Клавиши

| Клавиша | Название в настройках | Что делает |
|---|---|---|
| **J** | Дым: ВСЕ стойки в радиусе | Переключает активность всех стоек в 32 блоках |
| **Z** | ПК-стены: режим СЕРВЕРАМ ПИЗДА | Alert всем ПК-сетапам в 32 блоках + звук |
| **U** | Меню дыма | GUI настройки потолочного дыма |
| **P** | Детонатор: БАБАХ | Мгновенный взрыв текущего выделения |

## Звук и атмосфера

- **Гул кулеров** у активных стоек — клиентский локальный (см. модуль 1).
- Тумблер ПК-алерта играет звук один раз из центра действия.
- При взрывах — взрывные/огненные звуки по сцене блоками, без спама.

## Известные замечания

- Старые модели стены `m_*3` (сетка 3×4) удалены — постройки, сделанные
  на них в ранних версиях, будут битыми. Дев-мод, перестрой сетапы.
- GUI на скринштах не светится — для съёмки с Replay Mod снимай со стороны
  (как и планировалось).
- Английская локаль — описательная, основной язык ролика — русский (`ru_ru`).

## Сборка и CI

```bash
./gradlew build   # Java 21, gradle 8.10.2 (wrapper), fabric-loom 1.8-SNAPSHOT
```

GitHub Actions собирает ветку и PR, артефакт `serverrack-jar`.
Актуальный пул-реквест: **#2** — модуль стоек + ПК-стена + детонатор,
зелёные чеки, mergeable.
